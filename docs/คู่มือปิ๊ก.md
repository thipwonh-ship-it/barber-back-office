## กรอกยอด — โอน กับ ทิปโอน
ตัวอย่าง ลูกค้าโอน 850 (ค่าตัด 800 + ทิป 50) และจ่ายเงินสดอีก 400

| ช่อง | ใส่ | หมายเหตุ |
|---|---|---|
| เงินสด | 400 | |
| โอน | **850** | ยอดตามสลิป รวมทิป |
| ทิปโอน | **50** | ดูจากสมุดช่าง |
| รวม (ยอดตัด) | 1,200 | ระบบคิดเอง = เงินสด + โอน − ทิปโอน · ค่าแรงคิดจากยอดนี้ |

แถบใต้ชื่อช่างต้องเขียวทั้ง 2 แถบ
- **สลิป = โอน** · แดง = สลิปขาด/เกิน → แจ้งช่าง เช้าวันใหม่ตรวจอีกครั้ง
- **ทิปโอน = ที่ช่างกด หยิบเงินสด › ทิป** · แดง = ให้ช่างกดเมนูให้ครบ (เงินสดลิ้นชักหักตามที่ช่างกด)

## เงินโอนลูกค้าโลตัส + วงเงินสำรอง (บันทึก › 💵 เงิน)
- เงินโอนลูกค้าโลตัสเข้า**บัญชี owner** · owner กรอก "เข้าจริง" จากแอปธนาคารทุกวัน · ถ้าไม่ตรงกับ โอน ที่กรอก จะมีไลน์แจ้ง + ขึ้นกล่อง "ต้องดู" → ตรวจสลิป/ยอดกับช่าง แล้วแก้ที่ กรอกยอด
- **วงเงินสำรอง** = เงินในบัญชีผู้จัดการ ใช้ได้ 2 อย่างเท่านั้น: โอนค่าแรงปอน (กดที่การ์ดโอนรายวัน) และรายการที่**โทรขอ owner แล้ว**
- ทุกรายการที่ใช้ต้องลง "➖ ลงรายการใช้วงเงินสำรอง" · ส่วนตัวต้องเลือก **ส่วนตัว: ให้** หรือ **ส่วนตัว: เบิก** (เบิก = หักเงินเดือน)
- owner เติมวงเงินตามรายการที่ลงไว้ → มีไลน์แจ้งเมื่อเติม · ลงผิดกด "ยกเลิก" ท้ายรายการ

## งานประจำวัน
1. ระหว่างวัน: รับจอง → + จองคิว → 📤 ส่งกลุ่ม · อนุมัติลา
2. กลางคืน (ร้านปิด): บันทึก › กรอกยอด ทั้ง 3 ร้าน (แถบสลิป/ทิปต้องเขียว) · ลงรายจ่าย · ลงรายการใช้วงเงินสำรอง
3. ทุกเช้า: บันทึก › เงิน → โอนปอน (ยอด 2 วันก่อน) · หน้าแรก → ร้านช่างปิ๊ก
4. ดูหน้าแรก "ต้องดู" ให้เป็น ✓ ก่อนเลิกงาน

กฎการลา: ทุกร้านต้องมีช่าง ≥ 1 คน · Bow หยุด → M ไป Kraft → Pond หยุดไม่ได้ · Phoom/Leko ห้ามหยุดพร้อมกัน · แจ้งล่วงหน้า 7 วัน (ยกเว้นป่วย)

คำสั่งในไลน์: `สถานะ` = ใครเข้างานวันนี้ · `คู่มือ` · `ล้างเครื่อง`
