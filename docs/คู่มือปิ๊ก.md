# คู่มือปิ๊ก — แอป Dashboard

**เปิดแอป**: https://thipwonh-ship-it.github.io/barber-back-office/admin.html → ล็อกอิน LINE ครั้งเดียว (เครื่องจำ 90 วัน) → แชร์ → "เพิ่มไปยังหน้าจอโฮม" จะได้ไอคอน ✂️
(ก่อนใช้ครั้งแรก พิมพ์ `ผูกปิ๊ก <Admin PIN>` ในไลน์ OA)

| เมนู | ทำอะไร |
|---|---|
| 📍 วันนี้ | ใครเข้างาน/สาย · หัว/ยอดวันนี้ต่อร้าน · เดือนนี้ vs เป้า · เงินสดคงเหลือควรมี · ปอนค้างโอน |
| ✏️ กรอกยอด | เลือกวัน + ร้าน → ใส่ หัว / ยอดขาย / เงินสด / โอน ต่อช่าง → บันทึก · ระบบคิดค่าแรงให้ (แก้ได้ในช่อง "แก้ค่าแรง") · ลบแถว = ล้างหัวและยอดให้ว่างแล้วบันทึก |
| 🧾 รายจ่าย | วันที่ ร้าน ประเภท จำนวน รายละเอียด แนบใบเสร็จได้ · "เบิกช่าง" เลือกชื่อช่าง → ระบบแจ้งช่าง · "จ่ายจาก": เงินสดร้าน = หักเงินสดในร้าน / โอน = ไม่กระทบ |
| 💸 โอนรายวัน | รายการค้างโอนของปอน (ยอดของ 2 วันก่อน) → ติ๊กวันที่โอน แนบสลิป → บันทึก → ระบบแจ้งปอน |
| 📊 รายเดือน | รายวันแยกร้าน · ต่อช่าง · หัว vs เป้า · รายจ่าย · กำไรต่อร้าน |
| 💰 เงินเดือน | ตารางสุทธิวันที่ 2 (ปิดงวด/โอนแล้ว ทิพย์เป็นคนกด) |

คำสั่งในไลน์: `สถานะ` = ใครเข้างานวันนี้ · `คู่มือ` · `ล้างเครื่อง`
