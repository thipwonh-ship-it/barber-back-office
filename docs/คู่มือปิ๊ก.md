## กรอกยอด — โอน กับ ทิปโอน
ตัวอย่าง ลูกค้าโอน 850 (ค่าตัด 800 + ทิป 50) และจ่ายเงินสดอีก 400

| ช่อง | ใส่ | หมายเหตุ |
|---|---|---|
| เงินสด | 400 | |
| โอน | **850** | ยอดตามสลิป รวมทิป |
| ทิปโอน | **50** | ดูจากสมุดช่าง |
| รวม (ยอดตัด) | 1,200 | ระบบคิดเอง = เงินสด + โอน − ทิปโอน · ค่าแรงคิดจากยอดนี้ |

แถบใต้ชื่อช่างต้องเขียวทั้ง 2 แถบ
- **สลิป = โอน** · แดง = สลิปขาด/เกิน → แจ้งช่าง เช้าวันใหม่ตรวจอีกครั้ง
- **ทิปโอน = ที่ช่างกด หยิบเงินสด › ทิป** · แดง = ให้ช่างกดเมนูให้ครบ (เงินสดลิ้นชักหักตามที่ช่างกด)

## เงินโอนลูกค้า 3 ร้าน + วงเงินสำรอง (บันทึก › 💵 เงิน)
- เงินโอนลูกค้าทั้ง 3 ร้านเข้า**บัญชี owner** (ราม 1 บัญชี · โลตัส + Kraft 1 บัญชี) · ระบบเทียบ **โอนที่กรอก** กับ **สลิปที่ช่างส่ง** ทุกวัน — ต้องตรงกันทุกร้าน
- บอทตรวจ**ผู้รับบนสลิป**: ถ้าไม่ใช่บัญชีของร้านนั้น ขึ้น ⚠ ใต้ชื่อช่างในหน้ากรอกยอด + กล่อง "ต้องดู" → แตะดูรูป · โอนผิดจริง = ตรวจ QR ที่ร้าน/คุยกับช่าง · ผู้รับถูกแล้ว (บอทอ่านพลาด) = กด **"ผู้รับถูกแล้ว"**
- owner กรอก "เงินเข้าบัญชีจริง" **เดือนละครั้ง** (วันที่ 1) · ถ้าไม่ตรง จะมีไลน์แจ้ง → ไล่ดูรายวัน แล้วแก้ที่ กรอกยอด
- **วงเงินสำรอง** = เงินในบัญชีผู้จัดการ ใช้ได้ 2 อย่างเท่านั้น: โอนค่าแรงปอน (กดที่การ์ดโอนรายวัน) และรายการที่**โทรขอ owner แล้ว**
- ทุกรายการที่ใช้ต้องลง "➖ ลงรายการใช้วงเงินสำรอง" · ส่วนตัวต้องเลือก **ส่วนตัว: ให้** หรือ **ส่วนตัว: เบิก** (เบิก = หักเงินเดือน)
- owner เติมวงเงินตามรายการที่ลงไว้ → มีไลน์แจ้งเมื่อเติม · ลงผิดกด "ยกเลิก" ท้ายรายการ

## งานประจำวัน
1. ระหว่างวัน: รับจอง → + จองคิว → 📤 ส่งกลุ่ม · อนุมัติลา
2. กลางคืน (ร้านปิด): บันทึก › กรอกยอด ทั้ง 3 ร้าน (แถบสลิป/ทิปต้องเขียว) · ลงรายจ่าย · ลงรายการใช้วงเงินสำรอง
3. ทุกเช้า: บันทึก › เงิน → โอนปอน (ยอด 2 วันก่อน) · หน้าแรก → ร้านช่างปิ๊ก
4. ดูหน้าแรก "ต้องดู" ให้เป็น ✓ ก่อนเลิกงาน

กฎการลา: ทุกร้านต้องมีช่าง ≥ 1 คน · Bow หยุด → M ไป Kraft → Pond หยุดไม่ได้ · Phoom/Leko ห้ามหยุดพร้อมกัน · แจ้งล่วงหน้า 7 วัน (ยกเว้นป่วย)

คำสั่งในไลน์: `สถานะ` = ใครเข้างานวันนี้ · `คู่มือ` · `ล้างเครื่อง`

## กรอกยอด — ย้อม / เคมี (ตั้งแต่ ธ.ค. 69)
- กด **+ ย้อม / เคมี** ใต้ชื่อช่าง → กรอก**ยอดบิลเต็ม** (รวมค่าตัดถ้ามี)
- ย้อมดำสีธรรมชาติ: ช่างได้ **50%** ของบิล · ดัด/ยืด/เคมีอื่น: ช่างได้ **40%** ของบิล
- Kraft: ใส่ **จำนวนหัวที่เป็นงานย้อม/เคมี** ด้วย (หัวพวกนี้ไม่คิด 200/หัว ซ้ำ) · ทุกหัวยังนับเข้าเป้า
- ระบบโชว์ที่มาของค่าแรงใต้ช่อง เช่น "ตัด 4 หัว × 200 = 800 + ย้อม 800 × 50% = 400"

## กรอกยอด — 🧴 ขายผลิตภัณฑ์
- อยู่ใต้รายชื่อช่าง เหนือ "เงินสดนับได้" · 1 แถว = 1 รายการขาย: ช่าง · สินค้า · ชิ้น · ยอด · **เงินสด/โอน** (ต้องเลือก)
- ค่าสินค้าไม่นับหัว ไม่เข้าค่าแรง · เป็นรายได้ร้าน (กำไรขาดทุน)
- ช่างหยิบค่าคอม 50/ชิ้น จากเงินสดเอง + กดเมนู หยิบเงินสด › ขายผลิตภัณฑ์ → ระบบเทียบให้: เขียว = ครบ · เหลือง = รอหยิบ · แดง = หยิบเกิน (มีหยิบแต่ไม่มีรายการขาย → ดูสมุดแล้วเพิ่มรายการ)
- รับเงินสด → นับเข้า "เงินสดควรมี" · รับโอน → นับรวมกับสลิปของช่างคนนั้น
- รายการสินค้า/ราคา: owner แก้ในชีต ตั้งค่า I60:K69 · ไม่มีในรายการ เลือก "อื่นๆ…" แล้วพิมพ์ชื่อ

## เงินสดนับได้ (บันทึก › กรอกยอด — ใต้รายชื่อช่าง)
- **บังคับทุกร้านทุกคืน** — ไม่ใส่ บันทึกยอดไม่ได้ · 22:00 ถ้ายังปิดยอดไม่ครบ ระบบส่งไลน์เตือน
- ใส่ **ยอดนับเงินสดท้ายหน้าสมุด** (ตัวเลขที่ช่างเขียน ไม่ใช่ตัวเลขที่ระบบโชว์) → ระบบเทียบกับ "ระบบควรมี" (นับครั้งก่อน + ขายสด − หยิบ − เก็บ)
- ไม่ตรงและแก้ทันทีไม่ได้: ใส่เหตุผล → "บันทึกพร้อมส่วนต่าง" → ขึ้นให้ owner รับทราบ · วันถัดไประบบเริ่มเทียบจากยอดนับจริงของวันนี้
- เขียว = ตรง · แดง = ไม่ตรง ระบบบอกว่า "วันนี้ขาด/เกินเพิ่ม" เท่าไร และแสดงรายการหยิบของวันนั้น → เทียบกับหมายเหตุในสมุด
  - ช่างกดเมนูซ้ำ (สมุดเขียนครั้งเดียว) → ลบรายการซ้ำในแผ่น รายจ่าย
  - ช่างหยิบแล้วไม่ได้กด → ให้ช่างกดเมนู หรือเพิ่มรายการในแผ่น รายจ่าย
- ใบฝากเงินสดที่ขึ้น "ต้องตรวจ" (บันทึก › เงิน): เปิดดูรูป ถ้าถูกต้องกด "ดูใบฝากแล้ว ถูกต้อง"
