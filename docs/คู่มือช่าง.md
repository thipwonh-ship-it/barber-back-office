# คู่มือช่าง — Barber Back Office (ใช้ผ่านไลน์ OA @529vfxbd)

**ครั้งแรก**: เพิ่มเพื่อน OA → กดเมนู "ลงเวลา" → ใส่ PIN ที่ได้จากทิพย์ (ทำครั้งเดียว)

1. **ลงเวลา** — กดเมนู "ลงเวลา" → เลือกร้านที่ทำวันนี้ + กะ (10 หรือ 11) → กด **เข้างาน** (เปิด GPS และอยู่ที่ร้าน) · เลิกงานกด **เลิกงาน**
   - มาสาย ระบบบันทึกนาทีไว้ ไม่หักเงิน
   - สลับไปทำร้านอื่น เลือกร้านนั้นตอนกดเข้างาน
2. **หยิบเงินสด** — กดเมนู "หยิบเงินสด" → เลือกเหตุผล: รีวิว Google (50) / ขายผลิตภัณฑ์ (50) / ซื้อของเล็กน้อย (ใส่จำนวน + ซื้ออะไร) → บันทึก · ระบบแจ้งทิพย์ให้เอง
3. **เก็บเงินสด** (ทุกสัปดาห์) — กดเมนู "เก็บเงินสด" → ใส่จำนวน → เลือก "มีคนมาเก็บ" (ใส่ชื่อคนเก็บ) หรือ "โอนเข้าธนาคาร" (ต้องแนบรูปสลิป)
4. **สลิปค่าแรง** — หลังทิพย์โอนวันที่ 2 จะได้ข้อความสรุปในไลน์ · กดเมนู "สลิป" ดูสรุปรายวันและ PDF ย้อนหลัง
5. **หัว/ยอดขาย** — จดในสมุดเหมือนเดิม ปิ๊กกรอกเข้าระบบ
5.1 **ขายผลิตภัณฑ์** (แป้ง ปอมเมด ฯลฯ) — **จดในสมุดทุกครั้ง**: ชื่อสินค้า · ราคา · สด/โอน (**Kraft: บันทึกใน Loyverse ทุกครั้ง** + ส่งสลิปโอนเข้าแชทด้วย) แล้วค่อยกด หยิบเงินสด › ขายผลิตภัณฑ์ (50 ต่อชิ้น) · ไม่ได้จด ผู้จัดการจะถามกลับ

6. **คิวของฉัน** — การ์ด 📅 ในหน้าลงเวลา (วันนี้ / พรุ่งนี้ / เลือกวัน) · ลูกค้ามาแล้วกด ✓ มา · ไม่มากด ✗ · พิมพ์ "คิว" ในแชท OA ดูคิววันนี้+พรุ่งนี้
7. **จองคิวเอง** — ลูกค้านัดเราโดยตรง กด **+ จองคิว** ก่อนรับปากทุกครั้ง (ระบบกันเวลาชน) → ปุ่มเขียว 📤 ส่งเข้ากลุ่ม · บอทแท็กเราในกลุ่ม → กดไลก์รับทราบ
8. **ลา** — 🏖️ ขอลาหยุด ต้องแจ้งล่วงหน้า **7 วัน** · ป่วยกด **🤒 ลาป่วยวันนี้** · ปิ๊กอนุมัติ · ทุกร้านต้องมีช่าง ≥ 1 คน วันที่เพื่อนหยุดเราลาไม่ได้ ต้องสลับกัน (Pond/M/Bow · Phoom/Leko)

พิมพ์ "คู่มือ" ในไลน์เพื่อดูซ้ำ · ปัญหา: หน้าไม่ขึ้น → ปิดแล้วกดเมนูใหม่ · GPS ไม่ติด → เปิด Location ให้ LINE · ลืม PIN → ถามทิพย์

## กดแล้วรู้ได้อย่างไรว่าบันทึกแล้ว
- กดบันทึก (หยิบเงินสด / เก็บเงินสด) แล้วจะขึ้นจอใหญ่สีเขียว **"บันทึกแล้ว … บาท"** = เรียบร้อย กด "รับทราบ" **ไม่ต้องกดซ้ำ**
- จอสีเหลือง "วันนี้บันทึกไปแล้ว" = ยอดเดิมเคยกดแล้ววันนี้ ถ้าไม่ใช่รายการใหม่ให้กด "ไม่ใช่ · ยกเลิก"
- จอสีแดง "ยังไม่ได้บันทึก" = ยังไม่ลง กด "ลองใหม่" ได้ ระบบไม่ลงซ้ำ
- ดูรายการที่กดไปแล้ววันนี้ที่ **"วันนี้ฉันบันทึกแล้ว"** (ใต้ปุ่มเงิน) · กดผิดแจ้งผู้จัดการให้แก้
- **ฝากเงินสดเข้าธนาคาร**: แนบ "ใบฝากจากตู้" เท่านั้น · สลิปที่ลูกค้าโอนให้ส่งในแชทอย่างเดียว ห้ามแนบในเมนูเก็บเงินสด · ร้านรามไม่มีฝากธนาคาร (มีคนมาเก็บ)
- เขียน**ยอดนับเงินสด**ท้ายหน้าสมุดทุกวัน และเขียนหมายเหตุเมื่อหยิบทิป/ซื้อของ — ผู้จัดการใช้เทียบกับระบบ
