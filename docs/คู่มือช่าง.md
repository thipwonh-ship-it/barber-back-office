# คู่มือช่าง — Barber Back Office (ใช้ผ่านไลน์ OA @529vfxbd)

**ครั้งแรก**: เพิ่มเพื่อน OA → กดเมนู "ลงเวลา" → ใส่ PIN ที่ได้จากทิพย์ (ทำครั้งเดียว)

1. **ลงเวลา** — กดเมนู "ลงเวลา" → เลือกร้านที่ทำวันนี้ + กะ (10 หรือ 11) → กด **เข้างาน** (เปิด GPS และอยู่ที่ร้าน) · เลิกงานกด **เลิกงาน**
   - มาสาย ระบบบันทึกนาทีไว้ ไม่หักเงิน
   - สลับไปทำร้านอื่น เลือกร้านนั้นตอนกดเข้างาน
2. **หยิบเงินสด** — กดเมนู "หยิบเงินสด" → เลือกเหตุผล: รีวิว Google (50) / ขายผลิตภัณฑ์ (50) / ซื้อของเล็กน้อย (ใส่จำนวน + ซื้ออะไร) → บันทึก · ระบบแจ้งทิพย์ให้เอง
3. **เก็บเงินสด** (ทุกสัปดาห์) — กดเมนู "เก็บเงินสด" → ใส่จำนวน → เลือก "มีคนมาเก็บ" (ใส่ชื่อคนเก็บ) หรือ "โอนเข้าธนาคาร" (ต้องแนบรูปสลิป)
4. **สลิปค่าแรง** — หลังทิพย์โอนวันที่ 2 จะได้ข้อความสรุปในไลน์ · กดเมนู "สลิป" ดูสรุปรายวันและ PDF ย้อนหลัง
5. **หัว/ยอดขาย** — จดในสมุดเหมือนเดิม ปิ๊กกรอกเข้าระบบ

พิมพ์ "คู่มือ" ในไลน์เพื่อดูซ้ำ · ปัญหา: หน้าไม่ขึ้น → ปิดแล้วกดเมนูใหม่ · GPS ไม่ติด → เปิด Location ให้ LINE · ลืม PIN → ถามทิพย์
