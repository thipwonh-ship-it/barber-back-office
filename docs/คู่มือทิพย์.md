# คู่มือแอดมิน (ทิพย์) — Barber Back Office

แอป Dashboard: https://thipwonh-ship-it.github.io/barber-back-office/admin.html (ทำได้ทุกอย่างที่ปิ๊กทำ + เมนูเจ้าของ) · ชีต: Barber Back Office 2026

## งานประจำ
- **ต้นเดือน** ตั้งเป้าหัว: แอป → รายเดือน → "ตั้งเป้า" ข้างชื่อร้าน (หรือกรอก ตั้งค่า!A34:D57)
- **รายจ่ายที่ทิพย์จ่ายเอง** (ค่าเช่า น้ำไฟ โฆษณา): แอป → รายจ่าย → จ่ายจาก "โอน"
- **เงินสด**: แอป → วันนี้ → "เงินสดคงเหลือควรมี" = ตั้งต้น + เงินสดขาย − ช่างหยิบ/จ่ายเงินสดร้าน − เก็บไปแล้ว · ตั้งต้นที่ ตั้งค่า!K28:L30 (ยอดเงินสดในร้าน ณ วันที่เริ่มนับ)

## สิ้นเดือน (วันที่ 1–2)
1. เช็คว่าปิ๊กกรอกยอดครบถึงสิ้นเดือน (แอป → รายเดือน)
2. แอป → เงินเดือน → เลือกเดือน → **ปิดงวด** (ล็อกตัวเลข + บันทึกโบนัสเข้ารายจ่าย)
3. โอนเงินให้ช่างตามช่อง "สุทธิ" (ปอนได้เฉพาะ โบนัส − ปกส. − เบิก เพราะรับรายวันแล้ว)
4. กด **โอนแล้ว + ส่งสลิป** แนบรูปสลิปโอนต่อคน → ระบบส่งสลิป PDF + รูปเข้าไลน์ช่าง และเก็บใน Drive โฟลเดอร์ `Barber Back Office/สลิป yyyy-MM` (หรือพิมพ์ `โอนแล้ว yyyy-MM` ในไลน์ ถ้าไม่แนบสลิป)

## เพิ่ม / ลบช่าง
- แอป → เงินเดือน → **จัดการช่าง** → ชื่อ ร้านหลัก ขั้นต่ำ/วัน ปกส. PIN (ติ๊ก "จ่ายรายวัน" ถ้าแบบปอน) → บันทึก → บอก PIN ช่าง → ช่างกดเมนู "ลงเวลา" ในไลน์ใส่ PIN ครั้งแรก
- ช่างออก: ใส่วันออก → หายจากระบบ ข้อมูลเก่ายังอยู่ · ช่างเปลี่ยนเครื่อง/บัญชี LINE: ติ๊ก "ปลด LINE เดิม"

## คำสั่งในไลน์
`สถานะ` · `โอนแล้ว yyyy-MM` · `คู่มือ` · `ล้างเครื่อง` (ยกเลิกเครื่องที่จำไว้ทุกเครื่อง)
