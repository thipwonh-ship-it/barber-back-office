แอป Dashboard: https://thipwonh-ship-it.github.io/barber-back-office/admin.html (ทำได้ทุกอย่างที่ปิ๊กทำ + เมนูเจ้าของ) · ชีต: Barber Back Office 2026

## งานประจำ
- **ต้นเดือน** ตั้งเป้าหัว: แอป → 📊 รายงาน › ⚙️ ตั้งค่า → ตั้ง/แก้ (หรือกรอก ตั้งค่า!A34:D57)
- **รายจ่ายที่ทิพย์จ่ายเอง** (ค่าเช่า น้ำไฟ โฆษณา): แอป → ✏️ บันทึก › รายจ่าย → จ่ายจาก "โอน"
- **เงินสด**: แอป → ✏️ บันทึก › เงิน → "เงินสดในร้านควรมี" = ตั้งต้น + เงินสดขาย − ช่างหยิบ/จ่ายเงินสดร้าน − เก็บไปแล้ว · ตั้งต้นที่ ตั้งค่า!K28:L30 (ยอดเงินสดในร้าน ณ วันที่เริ่มนับ)

## เงินโอนลูกค้าโลตัส + วงเงินสำรองผู้จัดการ (✏️ บันทึก › 💵 เงิน)
- **ทุกวัน**: เปิดแอปธนาคาร ดูยอดเงินเข้าของร้านโลตัสรวมทั้งวัน → ใส่ที่ "เงินเข้าบัญชีจริง" (เลือกวันที่) → บันทึก · ไม่ตรงกับที่ปิ๊กกรอก = ขึ้นแดง + ไลน์แจ้งปิ๊กอัตโนมัติ · กรอกซ้ำวันเดิม = แก้
- ตาราง: กรอก (โอนที่ปิ๊กกรอก รวมทิป) / สลิป (ที่ช่างส่ง) / เข้าจริง / ต่าง
- **วงเงินสำรอง**: คงเหลือ = ตั้งต้น + เติม − โอนค่าแรงปอน − รายการที่ปิ๊กลง · เหลือต่ำกว่า 1,000 ขึ้นเตือนหน้าแรก
- **เติมวงเงิน**: โอนให้ปิ๊กก่อน → ใส่ยอด (ระบบใส่ยอดที่ขาดจากวงเงินให้) แนบสลิป → "เติม" → ไลน์แจ้งปิ๊ก
- รายการส่วนตัวของปิ๊ก: กด "→ ให้" / "→ เบิก" สลับได้ · ช่อง "ส่วนตัวเดือนนี้" = ยอดเบิกที่ต้องหักเงินเดือนปิ๊ก
- ตั้ง/แก้วงเงิน: 📊 รายงาน › ⚙️ ตั้งค่า → "วงเงินสำรองผู้จัดการ" → วงเงิน · วันเริ่ม · เงินในบัญชีผู้จัดการ ณ เช้าวันเริ่ม
- ทิปโอน: ปิ๊กกรอก ทิปโอน ในหน้ากรอกยอด ระบบเทียบกับที่ช่างกด หยิบเงินสด › ทิป · ไม่ตรงขึ้นกล่อง "ต้องดู"

## สิ้นเดือน (วันที่ 1–2)
1. เช็คว่าปิ๊กกรอกยอดครบถึงสิ้นเดือน (แอป → รายงาน › รายเดือน · หรือดูกล่อง "ต้องดู" หน้าแรก)
2. แอป → รายงาน › เงินเดือน → เลือกเดือน → **ปิดงวด** (ล็อกตัวเลข + บันทึกโบนัสเข้ารายจ่าย)
3. โอนเงินให้ช่างตามช่อง "สุทธิ" (ปอนได้เฉพาะ โบนัส − ปกส. − เบิก เพราะรับรายวันแล้ว)
4. กด **โอนแล้ว + ส่งสลิป** แนบรูปสลิปโอนต่อคน → ระบบส่งสลิป PDF + รูปเข้าไลน์ช่าง และเก็บใน Drive โฟลเดอร์ `Barber Back Office/สลิป yyyy-MM` (หรือพิมพ์ `โอนแล้ว yyyy-MM` ในไลน์ ถ้าไม่แนบสลิป)

## เพิ่ม / ลบช่าง
- แอป → รายงาน › ตั้งค่า → **เพิ่ม / แก้ / ช่างออก** → ชื่อ ร้านหลัก ขั้นต่ำ/วัน ปกส. PIN (ติ๊ก "จ่ายรายวัน" ถ้าแบบปอน) → บันทึก → บอก PIN ช่าง → ช่างกดเมนู "ลงเวลา" ในไลน์ใส่ PIN ครั้งแรก
- ช่างออก: ใส่วันออก → หายจากระบบ ข้อมูลเก่ายังอยู่ · ช่างเปลี่ยนเครื่อง/บัญชี LINE: ติ๊ก "ปลด LINE เดิม"
